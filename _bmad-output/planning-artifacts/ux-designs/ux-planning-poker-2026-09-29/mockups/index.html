Maquettes de Planning Poker

Les écrans tels qu'ils sont dans le front aujourd'hui, avec la feuille de style de l'application (app.css, copie de frontend/src/styles.css). Chaque planche montre les écrans dans un cadre de navigateur ou de téléphone ; un clic sur un bouton d'un écran mène à l'écran qu'il produit, et les liens « › » sous chaque légende suivent les parcours.

Pour les remettre à jour après un changement d'écran : adapter les gabarits de generer.mjs puis lancer node generer.mjs. En cas de conflit, EXPERIENCE.md et DESIGN.md font foi, pas ces maquettes.

Flux 1 : Eric anime l'affinage

Sur PC, en observateur

  1. Accueil : pseudo prérempli, « J'observe », cartes de la session.
  2. Session vide : le lien, « Copier le lien » et « QR code ».
  3. Session, tour caché : 9 votes sur 12, main grisée.
  4. Tour révélé : résultat dans la barre d'action, « Nouveau tour ».

Flux 2 : Sofia vote depuis son téléphone

Sur téléphone, en thème sombre

  1. Rejoindre : le lien ouvert, « Je vote » par défaut.
  2. Pseudo pris : message sous le champ, saisie conservée.
  3. Session, tour caché : carte 8 choisie, tiroir de la main.
  4. Tour révélé, consensus : tiroir replié, résultat condensé.
  5. Reconnexion : bandeau ambre, actions inactives.
